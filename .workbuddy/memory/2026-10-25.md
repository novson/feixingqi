## 棋盘三次返工：按《棋盘.png》重做（用户第二次批评「完全没还原图片」）

- 第二次被否：我做的是 Ludo 式方环 + 外挂小机库。参考图其实是**中国经典飞行棋**：
  方形双层轨道 + 四角大圆角机库（白虚线框 + 2×2 白圈飞机）+ 四条对角彩条（终点通道）
  + 中心四色圆盘（带白色飞机）+ 云朵天空 + 左「飞行棋 Fly Chess」右「起飞，向着更远的地方！」。
- 最终几何（`board.js` 全重写，13×13 网格，CELL=64，VIEW=892）：
  - 轨道 = 方形双层：每边 7 外 + 7 内 = 14 格，56 格；环序 = 外圈 28 格（从上方中点顺时针）
    + 内圈 28 格（从内圈上方中点顺时针）。起飞点 = 0/14/28/42 → 上中点(外)/下中点(外)/上中点(内)/下中点(内)。
  - 四角 3×3 机库（座位 0..3 = 左上/右上/右下/左下，颜色 = 红/蓝/黄/绿，与参考图角位一致）；
    机库底板外扩 6px + 大圆角，让边框角格被机库「切」住（参考图的切角三角效果）。
  - 终点通道 = 机库内角 → 中心的对角彩条（每格带小飞机图标）；5 人以上第 5–8 队无独立机库，
    飞机停在自己起飞格、通道从起飞格径向进中心（人多时隐藏标题避免被压）。
  - 中心圆盘 GOAL_RADIUS=76，扇区朝向各自机库。
- **关键规则变更**：`FLY_DISTANCE` 由 TRACK/2(28) 改为 TRACK/4(14)。原因：双层轨道下
